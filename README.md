# claims-platform-study

Monorepo del plan de estudio de arquitectura de software de Antonio (12 meses, ~430 h).
Dominio de referencia: gestión de siniestros de seguros.

- **Módulo 1 — `claims-core`** (meses 1–3): fundamentos formales y plataforma de datos distribuida.
- **Módulo 2 — `claims-platform`** (meses 4–7): cloud, plataforma, resiliencia y cadena de suministro.
- **Módulo 3 — `claims-intelligence`** (meses 8–10): pendiente de detallar en el plan.
- **Módulo 4** (transversal, todo el año): arquitectura como disciplina — ADRs, C4, arc42.
